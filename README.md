# WigetBUS

Malý desktopový widget pro Windows (WPF / .NET Framework 4.7.2) — digitální hodiny s kalendářem, který sedí na ploše.

## Funkce

- Digitální hodiny (sbalený/rozbalený režim)
- Kalendář s českými jmeninami a státními svátky (2025–2035)
- Budíky
- Ukládání nastavení a dat do `%AppData%\WigetBus`

## Spuštění

Otevřít `WigetBus.sln` (nebo `WigetBus.slnx`) ve Visual Studiu, obnovit NuGet balíčky a sestavit (Release/Debug).

## Technologie

- C# / WPF, .NET Framework 4.7.2
- Newtonsoft.Json pro ukládání dat
